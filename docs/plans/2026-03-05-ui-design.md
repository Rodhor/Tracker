# UI Design — tasktracker

**Date:** 2026-03-05
**Status:** Approved — ready for Figma + implementation

---

## Screens

### 1. Dashboard

**Layout:** Two-column, max-width 900px, horizontally centered on the page.

**Page:** `bg-zinc-950 min-h-screen flex items-center justify-center p-8`

**Both columns:** `bg-zinc-900 border border-zinc-800 rounded-xl p-6`

---

#### Left column — Task list

- Heading: `text-zinc-100 text-xl font-semibold` → "Tasks"
- Task rows: `flex items-center justify-between gap-4 py-3 border-b border-zinc-800`
  - Task name: `text-zinc-100 text-sm`
  - Status badge (pill): `text-xs font-medium px-2 py-0.5 rounded-full`
    - todo → `bg-zinc-700 text-zinc-300`
    - in_progress → `bg-blue-900 text-blue-300`
    - done → `bg-green-900 text-green-300`
  - Start timer button: `text-zinc-400 hover:text-indigo-400` icon/text button
- Add-task form (bottom of card):
  - Input: `bg-zinc-800 border border-zinc-700 rounded-lg text-zinc-100 placeholder-zinc-500 text-sm px-3 py-2`
  - "Add" button: `bg-indigo-600 hover:bg-indigo-500 text-white text-sm font-medium px-4 py-2 rounded-lg`

---

#### Right column — Timer panel

**Idle state:**
- Muted text: `text-zinc-500 text-sm` → "No active timer"

**Active state:**
- Task name: `text-zinc-300 text-sm`
- Elapsed time: `text-indigo-400 font-mono text-4xl font-bold tracking-tight` → e.g. `00:12:34`
- "Stop" button: `bg-red-600 hover:bg-red-500 text-white text-sm font-medium px-4 py-2 rounded-lg`

---

### 2. Quick-add popup

**Size:** ~420 × 100px (opened in browser `--app` mode)

**Page:** `bg-zinc-950 h-screen flex items-center justify-center px-4`

- Input: `autofocus`, `bg-zinc-900 border border-zinc-700 rounded-lg text-zinc-100 placeholder-zinc-500 text-sm px-4 py-3 w-full`
- Submit on Enter (or submit button: `bg-indigo-600 text-white px-4 py-3 rounded-lg`)

---

## Typography

- Font: system sans-serif (`font-sans`) for all UI text
- Timer display: `font-mono` for the elapsed time only
- No custom fonts — stays with Tailwind's default stack

---

## Design decisions

- **No shadows or gradients** — flat design keeps every style expressible as a single Tailwind utility class
- **Zinc scale for neutrals** — zinc has a slightly blue-tinted grey that pairs well with the indigo accent
- **Indigo accent** — consistent across the active timer, primary buttons, and hover states
- **Monospace timer only** — prevents layout shift as digits change width; everything else uses sans-serif
